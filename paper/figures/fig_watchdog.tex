\caption{The lease as a dead-man's switch. The watchdog is armed for exactly as long as a
session holds the lease, and any request from the holder renews it. Nothing needs to
detect that the agent has failed: the absence of renewal is itself the signal. After the
declared window the server acts alone, without the agent and without the network, and
recovery requires a verified \texttt{safety/reset}. This converts liveness of the
controlling process into a safety property, and is the clearest respect in which driving
an instrument differs from calling a software tool.}
