# Metrohm Titrino RS-232 remote control: what this package uses

Two generations, two protocols. Both end commands and answers with CR LF.

## Dialect `plus`: 870 KF Titrino plus

Source: 870 KF Titrino plus Manual, Metrohm 8.870.8003EN (10.2009), chapter 10.7 "Remote control via an
RS-232 connection" (manualslib.com/manual/1633783). Applies to the Titrino plus family (848, 870, 877, 890)
through the 6.2148.030 RS-232/USB box, port RS-232/2. Synchronous: every command is answered; the
instrument sends nothing on its own.

| Command | Meaning | Answer |
|---|---|---|
| `$G` | start, or continue after hold | `OK` |
| `$S` | stop | `OK` |
| `$H` | hold | `OK` |
| `$D` | status: Ready, Busy, Hold or Cond, plus 0 (no message) or a message number | status text and number |
| `$A(OK)` / `$A(CANCEL)` / `$A(YES)` / `$A(NO)` | acknowledge a message (must follow `$D`) | `OK` |
| `$L(method)` | load the method (name must exist and be unique) | `OK` or `E1` |
| `$Q(variable)` | request a variable | the value, or `E2` |
| any other | | `E3` invalid command |

Variables used: `R1` result, `MCV` end volume (mL), `DD` duration, `C00` sample size, `EP1` volume at EP1;
values are only available after the determination ends (status Ready). Others documented: `CI1/CI2` sample
identifications, `SMN1` mean, `TITER`, `CONC`, `FCT`, `DIV`, `EM1`, `ED1`, `MSV` start volume, `CV01/CV02`
blanks.

**Unverified**: the exact `$D` reply layout (word order, separator between the status word and the message
number; the driver looks for the status word anywhere in the line and takes the last integer as the
message); whether `$Q(R1)` answers a bare number or a labelled string (the driver takes the first number);
any command to enter the sample size (none is documented, so `sample_mass_g` is only recorded here); a
drift variable (none documented; `drift_ug_min` is null); the manual's own "Ready/Busy/Hold/Cond" spelling
as sent on the wire.

## Dialect `classic`: 758 KFD / 784 KFP / 719 S and other 7xx Titrinos

Sources: 758 KFD Titrino Instructions for Use, Metrohm 8.758.1203 (11.2001), chapter 3 "Operation via RS232
interface"; 784 KFP Titrino 8.784.1003, chapter 3; 719 S Titrino 8.719.1103 (manualslib.com). The 787 KF
Titrino manual (8.787.1003) refers to a separate command list from Metrohm.

Objects form a tree from the root `&`, levels separated by `.`, names abbreviable to a unique prefix,
values in double quotes (up to 24 ASCII characters; numbers up to 6 digits with a decimal point).

| Command | Meaning |
|---|---|
| `&Mode $G` | start the loaded method |
| `&Mode $S` / `&Mode $H` / `$C` | stop / hold / continue |
| `$D` | detailed status: global `$G` running, `$H` held, `$R` ready, `$S` stopped, then the detail (`.Mode.KFT.Cond.Ok`, `.Cond.Prog`, `.KFT1`, `.Req.Smpl` ...), then `;E<n>` errors |
| `&UserMeth.Recall "name"` | load a stored method (8 characters, no blanks) |
| `&SmplData.OFFSilo.ValSmpl "1.2345"` | sample size (6 digits, sign, decimal point); `.Id1/.Id2/.Id3`, `.UnitSmpl` |
| `&Info.TitrResults.RS.1.Value $Q` | calculated result 1 (read only; `.RS.1..9`) |
| `&Info.TitrResults.Var.C41 $Q` | end volume (mL); `C42` titration time (s); `C43` volume drift at the start of conditioning (uL/min); `C45` start volume |
| `&Info.ActualInfo.Titrator.{V,dVdt,Meas,T} $Q` | live values (`NV` not valid, `OV` overrange) |
| `&Config.Aux.Prog $Q` | program version, e.g. `"758.0022"` |

Error codes: E26 manual stop, E27 stop volume reached, E28 wrong object, E29 wrong value, E30 wrong
trigger, E31 not possible in the active status, E32 not possible during titration, E33 value corrected,
E43 output disabled by XOFF. The driver treats E26, E27 and E33 as information.

Drift water-equivalent: `C43` (uL/min titrant) times `titer_mg_ml` (mg water per mL) gives ug/min.

**Unverified**: whether a `$Q` answer echoes the object path before the quoted value (the driver takes the
first number in the line); the exact `$D` text of a KF conditioning state on a 784/787 (`.Cond.Ok` is from
the 758 KFD manual); the factory parity and data bits (9600 baud is stated).

## Not covered

Titrandos (851, 852, 901/906), coulometers (831, 899) and the 917: USB to tiamo/OMNIS or stand-alone; their
RS-232 is for balances and their "Remote" connector is a TTL start/stop/ready line interface. tiamo's
remote box and the OMNIS third-party integration are not publicly documented as command protocols. Mettler
V20/V30 KF: nothing public found. An open-source Python hack for a 716 Titrino (github.com/dkratzert/Titrino)
confirms the classic command framing at 9600 8N1.
